# There No Whale / Mihkihtah

The profile uses warm ivory, vivid orange, forest green and near black. Editorial serif headlines pair with plain sans serif labels. Meadow photography and a four-point star connect the graphics without borrowing the Swaga Labs mark.

| Color | Hex |
| --- | --- |
| Orange | #FF4D00 |
| Ivory | #F4F0E6 |
| Forest | #183729 |
| Ink | #11120F |

Assets live in `img/identity`. Run `python3 build_identity.py` to rebuild the SVG graphics. The generated hero is a separate PNG. `avatar.svg` is an optional matching avatar; it is not automatically applied to the GitHub account.

Diagrams show concepts and a toolkit, not measured proficiency or a claim about a specific deployed architecture. All profile images use relative repository paths.
